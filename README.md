# Carnot releases

Downloads for Carnot by Machael Studio: the mastering limiter. Loudness without waste.

Each release carries the signed, notarized macOS installer (`Carnot-<version>-macOS.pkg`: VST3,
AU, Standalone, `carnot` CLI) and the signed Windows installer (`Carnot-<version>-Windows.exe`:
VST3, Standalone, CLI). Source and issues live in the studio's private `carnot` repository.

Support: support@machael.studio
